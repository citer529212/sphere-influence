# Сферы влияния — Три короны

Играть: https://citer529212.github.io/sphere-influence/

Версия 0.4.0: объёмная карта по пользовательскому SVG, три державы и четыре захватываемых города на серых островах. Шестнадцать городов, цель — поддержка восьми за пятнадцать ходов.

- WASD и стрелки перемещают камеру относительно направления взгляда. Колесо приближает, перетаскивание вращает. В полях ввода и диалогах клавиши карту не двигают.
- Карта занимает весь экран. Компактная панель действий внизу справа сворачивается до строки выбора города. Стрелки и список переключают город с автоматическим подлётом; на телефоне панель расположена снизу. Меню, журнал и правила открываются поверх карты.
- Виктория / Синий Атлас: медиацентр за 4, усталость кампаний +14.
- Рэн / Красный Меридиан: укрепление +15 поддержки, кампании слабее на 3.
- Амина / Жёлтый Конкорданс: доход 5, цена кампании — 4 доверия.
- Сезон меняется каждые два хода. Весна +1 к кампании; полярная зима −3, засушливое лето −3, тропическая осень −2. Поправка указана в панели города.
- Вступление с разрывом карты можно пропустить. Вступление разделяет карту по реальным контурам трёх материков, серые острова остаются отдельными. Ходы соперников показаны последовательно прямо на карте: подлёт, дуга посланника, пульсация и числовой эффект. Постройка, защита, кампания, захват и доход имеют визуальную обратную связь; при победе — фейерверки и карточка PNG. Учитывается prefers-reduced-motion.

## Разработка

```sh
npm ci
npm run dev
npm run verify:release
```

Публикация GitHub Pages через `.github/workflows/deploy-pages.yml`. Выпускать из отдельного checkout репозитория sphere-influence, а не из родительского dictionary.

Исходник карты: `public/world-reference.svg`. `python3 scripts/import-map.py` воспроизводит `src/world/mapContours.ts`: 27 контуров, расположение и формы сохранены. Города и рельеф — геометрия Three.js; портреты и заставки — SVG/CSS. На каждом из четырёх серых островов есть нейтральный город. Для захвата нужны 55 поддержки и преимущество над соперниками в 5 пунктов; захватывать их могут игрок и обе другие державы. `python3 scripts/build-fragments.py` воспроизводит отдельные географические SVG-фрагменты для вступления.

Правила версии 3: выбор игрока сохраняется и включается в ссылку вызова. Сравниваются результаты за одинаковую державу. Старые сохранения версий 1–2 остаются в браузере, новая версия хранится отдельно (`spheres.session.v3`). Промежуточные кадры действий соперников не сохраняются: при перезагрузке в середине показа восстанавливается состояние до конца хода. Пропуск анимации применяет полный результат ровно один раз. Перезапуск/смена правителя заменяют только текущую попытку на этой карте. Серверного рейтинга и автоматической аналитики нет.

Проверки: последовательность ходов, нейтральные захваты и пороги, действия соперников и защита, географические фрагменты, экономика, лимиты решений, победа/поражение, все три державы и их особенности, климат, геометрия, нейтральные острова, сохранения и сравнение вызовов.
