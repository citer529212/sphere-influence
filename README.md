# Сферы влияния — остров Элион

Короткая браузерная стратегия на настоящем 3D-острове. Три вымышленные державы борются за поддержку 12 городов. Вы играете за Синий Атлас: привлеките восемь городов за 15 ходов.

**Игра:** https://citer529212.github.io/sphere-influence/

## Как играть

За ход можно принять два решения. Выберите город на карте или в списке. Его флаг, полоса названия и границы слоя «Инфоконтроль» показывают, чью повестку он поддерживает. Для перехода города поддержка Атласа должна опережать обоих соперников минимум на пять пунктов.

| Действие | Цена влияния | Эффект |
| --- | --- | --- |
| Медиацентр | 5 | +1 дохода за ход, пока город на вашей стороне; один центр на город |
| Привлечь город | 3 | Рост поддержки зависит от доверия и усталости, доверие −3 |
| Укрепить доверие | 2 | Поддержка +10, доверие +6, защита от ближайшего ответа соперников |

Базовый доход — 4 влияния за ход. Медиацентры усиливают доход. Кампании утомляют город; отдых и укрепление доверия уменьшают усталость. После завершения хода обе другие державы отвечают автоматически.

## Компьютер и телефон

На компьютере перетаскивание вращает карту, колесо меняет масштаб, правая кнопка сдвигает камеру. «К городу» приближает выбранное поселение, «Обзор» возвращает общий вид.

На телефоне карту можно пролистывать вместе со страницей. «Вращать карту» включает жесты камеры: один палец вращает, два приближают и перемещают. «Листать страницу» возвращает обычную прокрутку. При выборе города открывается панель снизу; «К карте» закрывает её. Нужен браузер с WebGL; при недоступной 3D-сцене города можно выбирать через список.

## Сохранения и вызов другу

Каждое изменение автоматически сохраняется в localStorage этого браузера. Партии разных карт хранятся отдельно. Незавершённая партия восстанавливается после смены даты. Для новой ежедневной карты есть кнопка «Карта на сегодня». Очистка данных браузера удаляет локальные сохранения; переноса между устройствами нет.

Ежедневный код — дата по Москве. Один код и одна версия правил дают одинаковую стартовую ситуацию и одинаковые ответы AI при одинаковых действиях. Кнопка вызова готовит текст со ссылкой. У победного результата ссылка также передаёт ход и доверие для сравнения: меньше ходов лучше, при равенстве лучше большее доверие. Неподдерживаемая версия правил отмечается предупреждением и не сравнивается.

Экран результата создаёт скачиваемую PNG-карточку 1200×900 с общим видом острова. Картинка формируется локально; если WebGL-снимок недоступен, используется схема острова. Отправка ссылки или картинки остаётся за игроком. Серверного рейтинга и проверки результатов нет.

[Инструкция для первого теста с 3–5 людьми](docs/PLAYTEST.md).

## Разработка

React, TypeScript, Vite и Three.js. Модели городов, рельеф, реки, леса и вода создаются кодом. Backend, аккаунты и API-ключи не нужны.

```sh
npm ci
npm run dev
```

Полная проверка выпуска:

```sh
npm run verify:release
npm run preview
```

Команда проверяет правила игры, сохранения, геометрию, общие вызовы, собирает `dist/` и проверяет бюджет начальной загрузки. Первоначальный интерфейс загружает примерно 60 КБ JavaScript gzip; 3D-движок и карточка результата загружаются отдельно. Полный объём приложения при этом не исчезает — он разделён на этапы загрузки.

Workflow `.github/workflows/deploy-pages.yml` публикует прошедшую проверки сборку в GitHub Pages при push в `main`. Используются относительные пути для размещения в подпапке репозитория. Service worker кеширует файлы только в области игры и не удаляет кеши других проектов.

## Основные файлы

- `src/App.tsx` — игровой интерфейс, подсказки и мобильная панель.
- `src/game/quickGame.ts` — правила и детерминированный AI.
- `src/game/session.ts` — проверенные сохранения и настройки.
- `src/game/challenge.ts` — коды карт, версии правил и сравнение вызовов.
- `src/components/WorldScene.tsx`, `src/world/` — 3D-карта, рельеф, модели и управление.
- `src/ui/` — звуки, окна, карточка результата и защита от ошибок загрузки.
- `scripts/` — проверки игры и выпуска.
- `src/AdvancedGame.tsx`, `src/components/MapView.tsx` — сохранённые исходные варианты сложного MVP и SVG-карты.

Сцена оптимизирована объединением зданий и instancing для лесов. В узком окне используется облегчённый профиль. Отрисовка приостанавливается, когда карта вне экрана или вкладка скрыта. Настройка уменьшения движения отключает волны, флаги и плавные перемещения камеры.

Это стилизованная 3D-стратегия. Игра является абстрактной критической симуляцией, а не инструкцией по реальной пропаганде или манипуляции. Автоматической аналитики и отправки игровых данных другим людям нет.
