# Сферы влияния — Три короны

Играть: https://citer529212.github.io/sphere-influence/

Версия 0.3.0: объёмная карта по пользовательскому SVG, три державы и четыре нейтральных серых острова. Двенадцать городов, цель — поддержка восьми за пятнадцать ходов.

- WASD и стрелки перемещают камеру относительно направления взгляда. Колесо приближает, перетаскивание вращает. В полях ввода и диалогах клавиши карту не двигают.
- Справа: предыдущий/следующий город и список с автоматическим подлётом. На телефоне города доступны через подписи, список регионов и панель города.
- Виктория / Синий Атлас: медиацентр за 4, усталость кампаний +14.
- Рэн / Красный Меридиан: укрепление +15 поддержки, кампании слабее на 3.
- Амина / Жёлтый Конкорданс: доход 5, цена кампании — 4 доверия.
- Сезон меняется каждые два хода. Весна +1 к кампании; полярная зима −3, засушливое лето −3, тропическая осень −2. Поправка указана в панели города.
- Вступление с разрывом карты можно пропустить. Между ходами — короткая заставка; при победе — фейерверки и карточка PNG. Учитывается prefers-reduced-motion.

## Разработка

```sh
npm ci
npm run dev
npm run verify:release
```

Публикация GitHub Pages через `.github/workflows/deploy-pages.yml`. Выпускать из отдельного checkout репозитория sphere-influence, а не из родительского dictionary.

Исходник карты: `public/world-reference.svg`. `python3 scripts/import-map.py` воспроизводит `src/world/mapContours.ts`: 27 контуров, расположение и формы сохранены. Города и рельеф — геометрия Three.js; портреты и заставки — SVG/CSS. Серые острова — нейтральный ландшафт без игровых городов.

Правила версии 2: выбор игрока сохраняется и включается в ссылку вызова. Сравниваются результаты за одинаковую державу. Старые сохранения версии 1 остаются в браузере, новая версия хранится отдельно (`spheres.session.v2`). Перезапуск/смена правителя заменяют только текущую попытку на этой карте. Серверного рейтинга и автоматической аналитики нет.

Проверки: экономика, лимиты решений, победа/поражение, все три державы и их особенности, климат, геометрия, нейтральные острова, сохранения и сравнение вызовов. [План игрового теста](docs/PLAYTEST.md).
