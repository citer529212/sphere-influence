# 0.13.0 — вступление из пяти авторских видео

Правила 6, баланс и сохранения совместимы с 0.12.0.

- Смонтированы три законченных вступления: общие встреча и разрыв карты, затем Атлас / Меридиан / Конкорданс в зависимости от выбранного правителя. Это три развязки вступления; победные экраны не менялись.
- Длительность каждой версии — около 20,76 секунды, 1280×720, H.264/AAC. Первый фрагмент немой, его тишина сохранена. Остальные дорожки взяты из исходников. Между первыми двумя сценами — растворение 0,3 с. MP4 используют faststart. Манифест содержит имена и SHA-256 оригиналов.
- В меню добавлен повторный просмотр вступления без сброса партии.
- Полноэкранный плеер сохраняет пропорции видео. Есть пауза, звук, пропуск и Escape. Настройка звука общая с игрой. При запрете автозапуска и при reduced motion доступен явный запуск. В скрытой вкладке фильм останавливается. Конец и пропуск ведут к существующему экрану правил.
- Если видео не загрузилось, остаётся прежняя иллюстрированная заставка. Фокус и клавиатура обрабатываются общим Modal.
- Автономный HTML содержит все три MP4 и постер (около 41 МБ), а не относительные ссылки. Сетевые фильмы не включены в JS и не загружаются все сразу. Service worker пропускает byte-range запросы и каталог фильмов, исключая ошибку Cache.put для ответа 206.

Проверки: 14 наборов тестов, TypeScript, production build и бюджет начального JS. MP4 проверены по контейнеру, кодекам, размерам, длительности, синхронности дорожек и faststart. Все три фильма полностью декодированы FFmpeg без ошибок, контактные листы просмотрены. Автономная сборка проверена на отсутствие внешних импортов и ссылок на MP4/постер.

Ограничение: взаимодействие плеера, политика автозапуска и мобильный вид не проверены в браузере из-за ранее заблокированного доступа инструмента. Запуск автономного файла также остаётся без браузерной проверки.
