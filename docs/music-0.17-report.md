# Музыкальная сборка 0.17.0

СФЕРЫ ВЛИЯНИЯ — 0.17.0, локальная сборка с музыкой

Автономная версия: откройте sphere-influence-0.17.0-offline.html в современном браузере. Интернет и сервер не нужны. Для начала музыки нажмите кнопку или выберите правителя; это требование браузера. Файл содержит все восемь музыкальных записей и все шесть видео. Раздел «Музыка» доступен на экране выбора, в меню и видеоплеере. Настройки музыки и звука видео/эффектов раздельны.

Веб-версия: sphere-influence-0.17.0-web.zip содержит готовое содержимое папки dist для GitHub Pages. Распакуйте в корень публикуемой папки, сохранив assets, music и cinematics. Для локального предпросмотра нужен HTTP-сервер; эта версия не предназначена для двойного щелчка по index.html. Публикация и отправка в GitHub не выполнялись.

Все произведения — Kevin MacLeod (incompetech.com). Музыка — CC BY 4.0, https://creativecommons.org/licenses/by/4.0/ . Источники, фрагменты и изменения записей перечислены в разделе «Музыка» и music/CREDITS.txt веб-версии. Условия остальных материалов определяются отдельно.

Тестирование: 18 групп автоматических проверок, TypeScript, production build, проверка ресурсов релиза; новая музыкальная группа дополнена проверками всех трёх финалов и смены вкладки во время загрузки. Все MP3 полностью декодированы FFmpeg, стыки проверены по сигналу. В автономном файле проверены SHA-256 всех восьми встроенных MP3 и отсутствие внешних путей воспроизведения. ZIP проверен на целостность и совпадение музыки.

Ограничения: браузерный инструмент в текущем чате ранее заблокирован. Реальный запуск file:// без сети, прослушивание стыков и синхронизация звука с видео на устройствах не выполнялись и требуют ручной проверки. Цифровая проверка стыка не гарантирует музыкально незаметного перехода. На устройствах с малой памятью большой автономный файл требует отдельной проверки. Если браузер запрещает хранилище для file://, настройки действуют до закрытия файла; блокировка звука или ошибка загрузки не препятствует игре.

Ручная проверка перед публикацией:
1. Без сети открыть автономный HTML. Убедиться, что после нажатия играет Dragon and Toast.
2. Выбрать по очереди три карточки: темы Атласа, Меридиана и Конкорданса. Начать партию; проверить звук вступления и возврат музыки после него.
3. Завершить ходы, открыть/закрыть меню и правила: тема не начинается заново.
4. Сменить громкость и отключение, закрыть и вновь открыть игру; загрузить сохранение каждой державы.
5. Проверить три победы: музыкальное начало вместе с роликом, продолжение на итогах без повторного запуска, паузу/продолжение и пропуск ролика. Проверить Sad Trio при поражении.
6. Свернуть/вернуть вкладку, проверить повтор каждого цикла и поведение с отключённой музыкой.
7. Повторить проверку веб-сборки через HTTP, в том числе при недоступном MP3. Проверить «Включить / повторить».
