# 0.15.0 — авторские победные финалы

Правила версии 6, сохранения и баланс не менялись.

- Три предоставленных ролика подключены к победе Атласа, Меридиана и Конкорданса. Около 5,04 секунды, 1280×720, H.264, faststart. Исходники не содержат звуковой дорожки; тишина сохранена. Подготовлены отдельные постеры и манифест SHA-256 исходников.
- После окончания ответного хода при настоящей победе показывается ролик, затем прежний экран результата с карточкой, статистикой и вызовом. Поражение и изолированное обучение не запускают его.
- Общий видеоплеер поддерживает паузу, явный запуск при ограничении autoplay/reduced motion, пропуск, Escape и остановку в скрытой вкладке. Для финала кнопка ведёт к итогам партии; звуковая кнопка скрыта, поскольку ролики немые.
- Повторное открытие итогов в текущей партии не запускает ролик автоматически; кнопка повтора позволяет посмотреть его снова. Новая попытка сбрасывает отметку просмотра. После перезагрузки страницы выигранная партия может показать ролик вновь. Ошибка видео не блокирует доступ к результату.
- В автономный HTML встроены все вступления, победные ролики и постеры. Сетевые фильмы остаются отдельными ресурсами и не попадают в начальный JS.

Проверки: 16 наборов тестов, TypeScript, production build и наличие медиа в dist. Проверены выбор фильма по правителю, показ только после победы и окончания анимации хода, пропуск повторного автопоказа, отсутствие фильма при поражении, контейнеры MP4, длительности, кодек, размер, отсутствие добавленной аудиодорожки и постеры. Все три файла полностью декодированы FFmpeg без ошибок; контактные листы просмотрены.

Ограничение: реальное воспроизведение и управление плеером в браузере по-прежнему требуют ручной проверки из-за ранее заблокированного доступа инструмента. Автономный HTML проверен сборкой, без запуска через file://.
