# Сфера влияния как приложение на Mac

Проект поддерживает компактный PWA-режим: игра остается обычным сайтом, но может открываться на macOS как отдельное приложение из Dock.

## Установка из Safari

1. Открой сайт игры: https://citer529212.github.io/sphere-influence/
2. В меню Safari выбери `File` -> `Add to Dock`.
3. Подтверди название `Сфера влияния`.
4. После этого игра появится в Dock и Launchpad.

## Установка из Chrome

1. Открой сайт игры: https://citer529212.github.io/sphere-influence/
2. Нажми значок установки в адресной строке или меню `...`.
3. Выбери `Install Сфера влияния`.

## Обновление приложения

После `git push origin main` GitHub Pages обновит сайт через Actions. Установленное приложение подтянет новую версию автоматически после перезапуска.

Если видна старая версия:

1. Закрой приложение.
2. Открой сайт в браузере и сделай жесткое обновление.
3. Открой приложение снова.
